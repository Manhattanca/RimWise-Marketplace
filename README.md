# RimWise 市场数据暂存仓库

本仓库用于保存 RimWise 的公开市场目录和排序清单，与软件源码仓库 `Manhattanca/RimWise` 分开维护。

当前目录为空，没有已上架排序。仓库提供公开静态目录、投稿校验和审核后的目录生成流程；RimWise 客户端接入正在验证。空目录不会显示虚构的排序内容。

## 数据位置

- `marketplace/index.json`：公开静态目录，初始格式为 `{"schemaVersion":1,"entries":[]}`。
- `marketplace/manifests/<github-login>/<sort-id>/<version>.json`：后续存放审核通过的排序文件，模组列表顺序即加载顺序。当前无此类文件。

目标读取方式：客户端缓存目录用于浏览，用户点击下载或下载并使用后才获取对应排序文件，并按目录中的 SHA-256 校验。下载公开数据不需要 GitHub 登录。

仅存放排序所需的模组标识、工坊编号、排序顺序及经授权的介绍等元数据。不托管任何模组本体、游戏文件、存档、日志、用户电脑路径或登录凭据。

## 投稿与审核

作者授权后由软件创建 PR，经维护者审核合并后上架。PR 校验仅使用基准分支中的可信工具读取候选 JSON，不执行投稿者的代码；校验通过不代表游戏内兼容性已验证。合并后，Actions 校验全部清单并更新 `marketplace/index.json`。已上架版本应保持不可变，更新使用新的版本文件。

投稿只允许增加符合上述路径的 JSON 清单。作者字段必须与 PR 发起账号相同；已经由其他作者使用的排序标识不能重复占用。校验失败的投稿不应合并。新作者首次触发 Actions 可能需要维护者批准运行。

这里的“暂存”不表示私密：公开仓库内的文件、提交记录和 PR 均可公开访问。不要提交敏感资料。
